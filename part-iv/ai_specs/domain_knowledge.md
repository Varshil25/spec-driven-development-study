# Domain knowledge
**Audience: AI Assistant + Team**

SDD = specification-first workflow for building software; Spec Kit = GitHub workflow tool; SD-KDP = OpenOwls' specification-first process for building knowledge; OpenKB = automated cross-referenced wiki approach. Distinguish correctness, security, traceability, time/effort and workflow governance. An empirical study reports measurements under stated conditions; a case report does not establish general effects. Tool documentation establishes features, not outcome improvements.

Evidence classes: `measured`, `reported case`, `observed`, `documented`, `claimed`, `argued`. Common mistakes: treating marketing percentages as replicated effects; conflating a constitution with implementation; assuming traceability means correctness; treating lack of evidence as proof of no effect. Extract tools, tasks, conditions, samples, measured outcomes, limits and contradictions. Preserve unknowns explicitly.
