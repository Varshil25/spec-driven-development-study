# Output format
**Audience: The Distiller — Contract**

Each `wiki/articles/<source-id>.md` contains:
1. YAML front matter: `source_id`, `title`, `evidence_class`, `source_url`, `source_sha256`.
2. `# Title`
3. `## Leader` — brief attributed extract, not a claim of validated synthesis.
4. `## Overview` — source-faithful extractive content, with source tag.
5. `## Limitations` — state baseline constraints or source limitations.
6. `## Sources` — exact URL and source ID.

Do not invent examples. Omit sections for which no supported content exists except mandatory sources. Future model-generated FAQ answers must be self-contained and source-attributed, with explicit Oracle perspective.
