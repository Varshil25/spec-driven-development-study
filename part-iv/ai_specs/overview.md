# Overview
**Audience: Business Sponsor**

Goal: test whether specification-first knowledge production can produce an evidence-traceable, queryable knowledge base about spec-driven software development, compared qualitatively with OpenKB. Audience: software engineers evaluating adoption and the independent-study examiner. Owner: study author.

Done means eight Oracle questions can be answered with verifiable source citations, the corpus and rights are audited, one-source and incremental tests are logged, and the OpenKB comparison uses the same corpus and model. Non-goals: claiming causal superiority from a structural comparison; reproducing copyrighted full texts in the wiki; automatically treating vendor claims as empirical evidence.

Success measures: number of trusted sources collected; unchanged/changed source reprocessing counts; source citation coverage; accepted/rejected outputs; coverage of eight key questions; setup and runtime effort; documented comparison dimensions.
