Each folder lists what was done in that week of the independent study, with
links to where the work lives in this repository. The tools, tasks and logs
stay in their own folders, because the scripts expect them there; the week
folders hold that week's reports and an index. Weeks are numbered as in the
study plan and the weekly reports.
