/speckit-constitution Establish the constitution for a small Python project. Principles: (1) Standard library only - no third-party runtime dependencies; (2) Fail loudly - invalid input produces a clear message and a non-zero exit status or an error response, never a silent wrong answer; (3) Every requirement is testable - each functional requirement maps to at least one automated pytest test; (4) Simplicity - the smallest design that meets the specification.
