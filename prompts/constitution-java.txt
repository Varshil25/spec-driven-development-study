/speckit-constitution Establish the constitution for a small Java service built on the Quarkus project skeleton in this repository. Principles: (1) No new dependencies - use only the libraries already declared in pom.xml; (2) Fail loudly - invalid input produces a clear error response, never a silent wrong answer; (3) Every requirement is testable - each functional requirement maps to at least one automated JUnit test; (4) Simplicity - the smallest design that meets the specification.
